# Página de docentes — Conecta Pana

- Página nueva: `docentes.html`.
- Usa la hoja de estilos común `styles.css` y el JavaScript compartido `app.js`.
- La tarjeta Docentes de `index.html` y los menús de las páginas enlazan a `docentes.html`.
- La portada usa `img/docentes.jpg` (recomendado: 1600 × 1200 px; la proporción se adapta al contenedor).
- Los perfiles usan iniciales como identificadores visuales; no se inventaron retratos personales.
- El buscador filtra nombres, cargos y formación académica.
- En algunos perfiles no se indicó formación académica; se deja expresamente sin completar.
